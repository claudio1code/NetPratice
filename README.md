## Descrição

O NetPractice é um projeto introdutório aos conceitos básicos de redes de computadores. O objetivo é aprender a configurar endereços IP, conectar dispositivos através de um roteador e compreender o papel de um gateway em uma rede. O projeto consiste em 10 exercícios (níveis) que devem ser concluídos em uma interface de treinamento.

## Instruções

1.  Para iniciar a interface de treinamento, você precisará de um arquivo `index.html` que pode ser encontrado na página do projeto.
2.  Abra o arquivo `index.html` em seu navegador.
3.  Insira seu login da intranet no campo apropriado.
4.  Selecione um nível e leia o objetivo cuidadosamente.
5.  Configure os elementos da rede (hosts, roteadores, interfaces) para alcançar a conectividade desejada.
6.  Após completar cada nível com sucesso, clique no botão "Get my config" para exportar sua configuração. Cada nível gera um arquivo de configuração.
7.  Salve os 10 arquivos de configuração exportados (`level1.json`, `level2.json`, ..., `level10.json`) na raiz deste repositório.

## Recursos

Este projeto aborda os seguintes conceitos de rede:

*   Endereçamento TCP/IP
*   Máscara de sub-rede (Subnet mask)
*   Gateway padrão (Default gateway)
*   Roteadores (Routers) e Switches
*   Camadas OSI
